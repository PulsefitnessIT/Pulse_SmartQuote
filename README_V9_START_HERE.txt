Pulse Fitness SmartQuote V9 — Historical Calculations Import (controlled pilot)

1. Install into a fresh folder. If migrating, make a BACKUP of your previous
   smartquote_local.db then copy it into this folder before launching V9.
2. Install requirements (start_windows.bat normally handles this), start,
   and sign in as a coordinator / manager.
3. Create a quote. Upload the previous Pulse agreement PDF.
4. Directly underneath, click Upload previous calculations and select the
   original .xls or .xlsx calculation sheet.
5. Historical pricing is joined by old product code; modern prices are
   calculated using the existing latest available SmartQuote catalogue RRP.
6. The 2025 Master Input file provided identity and console evidence, NOT
   latest approved RRP. In V9 two Skipton products still need updated RRP.
7. Historic-only references can show numeric estimates but are marked
   CURRENT RRP REQUIRED and keep the quote a DRAFT.
8. The fixed-price extension in the Skipton agreement must also be checked.

This is NOT a release for unrestricted customer use. V9 has local accounts,
not production central identity/database, and pricing source is provisional.
For the detailed audit, see V9_RELEASE_NOTES.md and the companion XLSX.
