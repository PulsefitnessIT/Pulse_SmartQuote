# SmartQuote V10 — File recognition & premium-strength source prices

## Automatic document identification

The single upload panel examines **PDF content** (invoice headers or existing maintenance agreement fields) and **Excel workbook headings**, not just filenames. Clearly recognised invoices automatically open the **read-only invoice preview**, and recognisable single asset lists go to their existing preview. Multiple invoices use the existing same-site batch preview. Unsupported, credit-note, scanned and ambiguous documents retain a manual document-type choice; no source is silently committed. Previous agreements and historic calculations retain an explicit Review click because their existing import API immediately mutates a quote. All quote protections and snapshots remain unchanged.

## Exact strength-console pricing

When current catalogue matching has no approved price, a **full source SKU plus corroborating model/console description** can now yield a numeric draft using the unique August 2026 master RRP. Where a legacy SKU is absent, a sufficiently distinctive premium strength spec may yield a draft only if all matching source candidates share one RRP. Display of the original installed SKU, serial and description remains unchanged. A reference SKU is **never an assertion that the customer's machine has that SKU**.

Verified synthetic descriptions:
- 305H-AEP: £9,011.14 source RRP; Gold 3% guide £270.33 annual / £22.53 monthly unit
- 310H-AEP: £8,948.58 source RRP; Gold 3% guide £268.46 annual / £22.37 monthly unit
- 314H-AEP: source SKU missing; uniquely priced description cohort references 314H-AEX at £9,438.75; Gold guide £283.16 annually / £23.60 monthly unit

All amounts are **draft source-based maintenance estimates only**. Tariffs, installed legacy configurations, rate group and commercial owner sign-off remain mandatory. Contradictory consoles, unclear descriptions, conflicting source RRPs, third-party manufacturers or duplicate-live-SKU conflicts must not be automatically priced. Main equipment list uses a compact display description; original full description remains available under Edit.
