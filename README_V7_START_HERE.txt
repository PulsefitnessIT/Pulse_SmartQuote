Pulse Fitness SmartQuote V7 — Quick Start
===========================================
1. Close V6 and back it up.
2. Extract this ZIP into a new folder. For existing quotations/users copy
   smartquote_local.db from V6 into the V7 folder BEFORE first launch.
3. On Windows, double-click start_windows.bat; sign in as normal.
4. NEW: Drop the KA Leisure XLSX into Upload Equipment (150 asset rows).
5. NEW: Upload previous agreement (PDF) for a renewal from a digital Pulse
   maintenance agreement with a readable Schedule 3 equipment schedule.
6. NEW: Edit line > Console/dropdown to set console; verify correct SKU.
7. NEW: Staff Users in the left menu appears for an administrator.

Use MASTER PRICE LIST (manager) to maintain product/RRP data.
Prices on ambiguous/obsolete machines cannot be verified automatically.
The local pilot is not approved for unrestricted customer issue.

Full details: README.md and V7_RELEASE_NOTES.md
